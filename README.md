# Nth Fibonacci Number Calculator

A Python implementation of the Nth Fibonacci number calculator using an iterative dynamic programming approach.

## Description

The Fibonacci sequence is a sequence where each number is the sum of the two preceding numbers:

`0, 1, 1, 2, 3, 5, 8, 13, ...`

This project implements a `fibonacci` function that calculates the Nth Fibonacci number efficiently without using recursion.

## Features

* Uses dynamic programming.
* Stores computed Fibonacci numbers in a `sequence` list.
* Uses an iterative approach instead of recursion.
* Supports non-negative integer inputs.

## Example

```python
fibonacci(10)
```

Output:

```text
55
```

## Complexity

* Time Complexity: O(n)
* Space Complexity: O(n)
